# 전력소비 예측 시스템

가정 내 환경 센서 데이터와 과거 전력 사용량을 기반으로 전력소비량을 예측하는 LSTM 기반 시계열 예측 프로젝트입니다.  
데이터 전처리, feature engineering, 딥러닝 모델 학습, 예측 결과 시각화, Streamlit 웹 서비스 구현까지 머신러닝 서비스 개발의 전체 흐름을 구현했습니다.

## 프로젝트 소개

본 프로젝트는 가정 내 환경 센서 데이터와 과거 전력 사용량 데이터를 기반으로 전력소비량을 예측하는 머신러닝 프로젝트입니다.  
실외 온도, 실외 습도, 실내 온습도, 조명 전력, 이슬점 온도, 기압, 시간 정보, 직전 전력 사용량 등의 변수를 활용하여 LSTM 기반 시계열 예측 모델을 학습하였고, 학습된 모델을 Streamlit 웹 애플리케이션으로 구현하여 사용자가 직접 조건을 입력하고 전력소비량을 예측할 수 있도록 구성했습니다.

단순히 모델 학습에 그치지 않고, 데이터 전처리, 시계열 특성 생성, 모델 학습, 예측 결과 시각화, 웹 서비스 구현까지 머신러닝 서비스 개발의 전체 흐름을 경험하는 것을 목표로 진행했습니다.

## 주요 기능

- 가정 내 환경 데이터 기반 전력소비량 예측
- 시간 정보를 sin/cos 주기성 변수로 변환하여 모델 입력에 반영
- 직전 전력 사용량 lag feature 생성
- LSTM 기반 시계열 예측 모델 학습
- Streamlit 기반 예측 웹 페이지 구현
- 단일 시점 전력소비량 예측
- 7일, 14일, 30일 단위 예측 결과 제공
- 실제 전력량과 예측 전력량 비교 그래프 시각화

## 데이터 전처리

원본 데이터의 날짜 컬럼을 datetime 형식으로 변환한 뒤, 시간 정보를 추출하여 모델 입력 변수로 활용했습니다.  
시간은 0~23 사이의 단순 숫자로 사용할 경우 시간의 순환성을 제대로 표현하기 어렵기 때문에, 다음과 같이 sin/cos 변환을 적용했습니다.

- Hour_sin
- Hour_cos

또한 전력소비량은 시계열 특성이 강한 데이터이므로, 직전 시점의 전력 사용량을 반영하기 위해 lag feature를 생성했습니다.

- Appliances_lag1
- Appliances_lag2
- Appliances_lag3

타깃 값인 전력소비량은 분포 안정화를 위해 log1p 변환을 적용한 뒤 모델을 학습했습니다.

## 모델 구조

본 프로젝트에서는 시계열 데이터 예측에 적합한 LSTM 모델을 사용했습니다.

모델 입력에는 48개 시점의 시퀀스 데이터를 사용했으며, LSTM 계층과 Dropout 계층을 조합하여 과적합을 완화하고자 했습니다.

```python
LSTM(64, return_sequences=True)
Dropout(0.2)
LSTM(32)
Dropout(0.2)
Dense(1)

학습 과정에서는 Adam optimizer와 MSE loss를 사용했으며, EarlyStopping을 적용하여 검증 손실이 개선되지 않을 경우 학습을 조기 종료하도록 구성했습니다.

## 모델 성능

테스트 데이터 기준 주요 평가 지표는 다음과 같습니다.

지표	값
RMSE	74.4037
MAE	32.7296
R²	0.3203

모델은 전력 사용량의 전체적인 변화 흐름을 예측할 수 있도록 구성되었으며, 실제값과 예측값을 그래프로 비교하여 모델의 예측 경향을 확인할 수 있습니다.

## 웹 애플리케이션 구성

Streamlit을 사용하여 학습된 LSTM 모델을 웹 애플리케이션 형태로 구현했습니다.

## 전력소비 예측 탭

사용자가 날짜를 선택하면 해당 시점의 환경 데이터가 기본값으로 입력됩니다.

사용자는 온도, 습도, 조명 전력, 기압, 과거 전력 사용량 등을 직접 수정할 수 있으며, 입력값을 바탕으로 모델이 예상 전력소비량을 예측합니다.

예측 결과는 표 형태로 제공되어 사용자가 입력 조건에 따른 예상 전력소비량을 쉽게 확인할 수 있도록 구성했습니다.

## 전력량 예측 결과 탭

사용자가 7일, 14일, 30일 중 예측 기간을 선택하면 해당 기간의 실제 전력량과 예측 전력량을 비교하여 제공합니다.

예측 결과는 표와 그래프로 함께 시각화하여 실제값과 예측값의 차이 및 전체적인 예측 경향을 확인할 수 있도록 구성했습니다.
